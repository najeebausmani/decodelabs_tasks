# DecodeLabs Data Analytics Internship Tasks

This repository contains a collection of four distinct projects covering the complete data analysis lifecycle: from raw data cleaning to exploratory analysis, SQL querying, and data visualization.

## 📂 Project Directory

### [Task 1: Data Cleaning & Preparation](./Task_1)
**Tools:** Python, Pandas, NumPy, ReportLab
*   **Objective:** Clean and prepare a raw e-commerce dataset for analysis.
*   **Key Actions:** Imputed missing values (CouponCode), removed duplicate OrderIDs, standardized dates to ISO-8601, normalized text fields, and fixed floating-point precision.
*   **Deliverables:** A clean Excel dataset, a Python cleaning script, and a PDF Change Log Report documenting the process (CR001–CR005).

### [Task 2: Exploratory Data Analysis (EDA)](./Task_2)
**Tools:** Python, Pandas, Matplotlib, Seaborn, ReportLab
*   **Objective:** Interrogate the cleaned dataset to uncover hidden patterns, trends, and outliers.
*   **Key Actions:** Calculated descriptive statistics (Five-Number Summary), identified outliers using the IQR method, mapped Pearson correlations, and analyzed categorical trends.
*   **Deliverables:** Visualizations (Histograms, Boxplots, Heatmaps, Bar charts), a Python EDA script, and an EDA PDF Report with business recommendations.

### [Task 3: SQL Data Analysis](./Task_3)
**Tools:** SQL (SQLite)
*   **Objective:** Answer core business questions using SQL alone.
*   **Key Actions:** Wrote 16 queries demonstrating proficiency in `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `COUNT/SUM/AVG`, `HAVING`, and `CASE` statements.
*   **Deliverables:** A SQL script (`project3_queries.sql`) and a PDF Report detailing the query logic, results, and insights (e.g., discovering a 41% cancellation/return rate).

### [Task 4: Data Visualization Story](./Task_4)
**Tools:** Data Visualization / Storytelling
*   **Objective:** Translate data findings into a compelling narrative for stakeholders.
*   **Key Actions:** Created a visual story highlighting the core business problem: *"Revenue is shrinking about 10% a year, and 41% of orders are cancelled or returned."* Focused on median vs. mean order value and quarterly revenue trends.
*   **Deliverables:** A PDF Presentation/Storyboard ("Orders Are Shrinking Data Visualization Story").
